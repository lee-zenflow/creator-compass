# Creator Compass GitHub 双语定位设计

## 目标

让 GitHub 访客在首屏快速理解 Creator Compass 的名称、目标用户和核心闭环，同时保持中文优先并提供自然、等义的英文表达。

## 最终文案

README 主标题：

> Creator Compass｜创作者罗盘

中文简介：

> 本地优先的 AI 创作者工作台，连接 IP 定位、内容策划、数据复盘与下一步行动。

English description:

> A local-first AI workspace connecting creator positioning, content planning, performance review, and next actions.

## 应用位置

- GitHub 仓库名继续使用 `creator-compass`，不改变仓库 URL。
- GitHub About 简介按“中文 / English”组合展示。
- README 首屏依次展示双语标题、中文简介和英文简介。
- README 其余功能说明、真实能力边界和本地运行方式保持不变。

## 边界

- 不声称已经接入抖音、小红书、B 站或公众号后台。
- 不声称已经公网部署、正式商业化或完成大规模用户验证。
- 不使用“全能、革命性、一站式”等无法验证的宣传词。
- 不为双语展示重复整份 README。

## 验收

- GitHub About 和 README 同时包含自然的中文与英文简介。
- README 的第一个标题为 `Creator Compass｜创作者罗盘`。
- 仓库名、公开地址、安装命令和产品真实边界不变。
