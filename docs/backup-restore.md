# 本机备份与恢复

产品内「我的 → 备份与恢复」提供可携带的加密备份。备份使用 scrypt 派生密钥和 AES-256-GCM 加密，文件清单逐项记录 SHA-256；恢复前先完整验证，不把半份数据写入当前产品。

## 备份内容

- 定位访谈、画像与定位报告
- 创作项目、方案、发布记录和复盘
- 任务、素材、平台账号标签与本地统计
- 经过治理的知识来源、切片、规则和引用记录
- 本地私有文件

备份不包含登录密码、会话、恢复码、主密钥和 DeepSeek Key。公开仓库也不应包含生成的 `.ccbackup` 文件。

## 创建备份

1. 打开「我的 → 备份与恢复」。
2. 输入至少 12 个字符且仅用于本次备份的口令。
3. 下载生成的加密备份，并把口令保存在与备份文件不同的位置。
4. 定期用一份非唯一数据做恢复演练，确认口令和文件都可用。

系统另外保留最近 7 份本机自动快照，用于恢复失败时回滚。自动快照不替代用户下载的异地备份。

## 恢复

1. 停止正在进行的 AI 生成和知识入库。
2. 上传加密备份并输入原口令。
3. 系统先校验版本、清单、哈希和数据库内容，再创建恢复前快照。
4. 恢复成功后重新登录，并重新填写 DeepSeek Key。
5. 抽查一条定位、创作、复盘、任务、素材和知识引用链。

如果恢复失败，系统保留原产品数据并尝试用恢复前快照回滚。不要手动覆盖 `private-storage`、`snapshots` 或 PostgreSQL 数据目录。

## 更换电脑

新电脑先安装并启动相同或更高版本的 Creator Compass，创建新的 Owner，再从产品内恢复备份。主密钥不随便携备份迁移，因此旧 DeepSeek Key 必须重新输入；这是刻意的安全边界。
